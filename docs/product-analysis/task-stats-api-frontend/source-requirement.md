# 前端任务统计展示需求（原始输入）

## 目标

为现有任务看板增加服务统计展示。前端将当前任务快照提交给既有接口文档定义的统计 API，并在页面展示服务统计；服务不可用时继续展示本地统计并提示用户。

## 范围

- 仅实现前端页面、请求适配器、开发/测试 mock 和前端测试。
- 后端接口文档是只读输入契约：`../task-stats-api/api-documentation.md`。
- 使用可注入 request adapter/mock 模拟真实 HTTP 响应，不新增或实现后端服务。

## 验收标准

- 页面加载、添加任务或切换完成状态时，请求 `POST /api/v1/tasks/summary`，请求体包含当前完整任务快照。
- 成功时展示 `total`、`pending`、`done`；请求期间显示 loading，完成显示 success。
- 空列表成功响应显示三个 0。
- 请求失败或返回非 2xx 时保留本地统计并提示“统计服务暂不可用”，不清空任务。
- 切换筛选不改变提交给服务的任务集合或统计数字。
- mock 仅在开发/测试显式启用，生产默认关闭；不修改后端文档或新增后端目录。

## 非目标

- 后端 HTTP handler、数据库、认证、部署或真实联调。
- 修改既有 API 文档、任务创建、筛选和 localStorage 语义。
