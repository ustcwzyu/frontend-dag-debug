# 产品需求：Agent 学习实验室后端服务

## 1. 需求概述

为当前零后端的 Agent 学习实验室单页站增加完整 API 服务：课程内容（三条学习路线、六类能力、本周实验、第一课完整课程）由后端 API 提供并持久化；新增简易账号登录；登录用户可保存个人学习进度（第一课完成状态、评估分、本周实验完成标记）。后端不可用时前端回退内联数据并提示「服务不可用」，页面照常可浏览。

## 2. 业务目标

- 站点由「零后端演示页」演化为「内容与进度均有服务端职责的完整前后端项目」。
- 学习进度真实持久化（SQLite），服务重启不丢失，换设备登录可恢复。
- 后端不可用或未登录时不阻断浏览：内容可降级展示，进度保存失败仅提示。

## 3. 需求范围

### 3.1 已确认需求

- 后端为 Node.js + Express + TypeScript；持久化使用 SQLite（Node 原生 `node:sqlite`，不引入额外原生依赖）。
- 课程内容 API：路线列表、能力地图、本周实验、第一课课程内容，均以 JSON 提供。
- 前端加载成功后使用服务数据渲染；加载失败（网络错误或非 2xx）回退内联数据，页面可用并显示「服务不可用」提示。
- 简易账号体系：注册（用户名+密码）、登录、会话令牌；账号密码单向散列存储，不落明文。
- 学习进度 API：按用户读写进度；进度字段为第一课完成状态（布尔）、第一课评估分（0–10 整数或空）、本周实验完成标记（布尔）、更新时间。
- 本地开发：前端 Vite dev server 与后端并存，`/api` 前缀请求由 Vite 代理到后端；生产构建后由后端进程同时提供静态资源与 API。
- 现有首页测试中「零网络请求、课程数据内联」断言随新契约更新（契约变化已确认接受）。
- `src/task-board.ts` 及 `test/task-board.test.mjs` 保持原样，不作改造。

### 3.2 非目标

- 邮箱验证、找回密码、OAuth、第三方登录、真实生产部署、HTTPS、开放跨域。
- 课程内容 CMS、后台管理、图片上传、富文本编辑器、多语言。
- 学习路线切换偏好持久化（维持现状：不写 localStorage）。
- 第一课课程内容新增教学章节或交互控件改版。

### 3.3 默认假设

- 本地 API 运行于 `http://localhost:3001`；前端 Vite 页面请求 `/api/v1/...` 相对路径，由 Vite 代理转发。
- SQLite 数据库文件存放于服务端数据目录，首次启动自动初始化内容与表结构；数据库文件不被纳入版本控制。
- 会话令牌由服务端签发（随机不可猜测）、持久化存储；演示环境不设过期时间或长期有效。
- 请求体为 JSON；未登录请求受保护端点返回 401；不存在的资源返回 404；字段/结构非法返回 400。
- 用户名唯一，用户名与密码均为非空字符串；密码强度的产品要求仅限「非空」，不强制长度复杂度（本地演示）。

### 3.4 未决事项

无。

## 4. 业务规则

- 内容 API 返回的数据与站点现状一致（三条路线、六类能力、本周实验、第一课现有章节结构）；内容语义变更需另行需求。
- 学习者标识 = 登录账号；未登录者只能浏览，不能读写服务端进度。
- 进度按用户隔离：任何用户只能读写自己的进度。
- 前端降级时不替换已展示内容、不白屏；「服务不可用」提示必须可见。
- 进度保存失败时前端保留本地值并提示失败原因，不得静默清零或回滚为旧值。
- 后端错误响应不得泄露堆栈、数据库内容或其他用户进度。
- 所有新后端端点与前端行为必须有 Node.js 测试覆盖（`node --test`）。

## 6. 前端用户故事

### FE-US-001 服务化课程内容与降级兜底

- 角色：浏览 Agent 学习实验室的用户
- 目标：看到由后端提供的路线、能力、实验与第一课内容；后端不可用时仍能浏览
- 价值：内容由服务端契约提供，前端可按契约校验与降级
- 入口：页面加载、刷新、路线切换
- 验收标准：AC-FE-001、AC-FE-002

### FE-US-002 简易账号登录

- 角色：希望保存学习进度的用户
- 目标：注册或登录后获得会话，用于保存个人进度
- 价值：进度与设备解耦，换设备可恢复
- 入口：进度面板内注册/登录表单
- 验收标准：AC-FE-003、AC-FE-004

### FE-US-003 学习进度保存与恢复

- 角色：已登录用户
- 目标：保存第一课完成状态、评估分与本周实验完成标记，再次登录后恢复
- 价值：学习状态可恢复、可归档
- 入口：进度面板
- 验收标准：AC-FE-005、AC-FE-006

## 7. 前端输出规范

### FE-US-001 服务化课程内容与降级兜底

- 页面/组件：首页（hero/路线/课程/能力地图/本周实验）
- 展示内容：服务端提供的路线、能力、实验、第一课内容；后台加载时沿用当前展示值
- 交互动作：页面加载即请求内容；加载成功后重渲染内容区域；失败时保持内联兜底数据并显示提示
- UI 状态：loading（沿用当前展示）、success（服务数据）、fallback（内联数据 + 服务不可用提示）
- 表单校验：无（内容为只读展示）
- 权限可见性：所有访问者可见，未登录也可浏览
- 边界处理：失败不替换已展示内容、不白屏；提示文案可见且不阻塞阅读

#### AC-FE-001 加载成功时展示服务端课程数据

Given：
- 后端服务可访问，内容端点返回合法 JSON。
- 用户打开站点首页。

When：
- 页面加载完成并收到内容响应。

Then：
- 路线列表展示后端返回的三条路线（入门/构建/进阶），默认选中「入门」且 aria-pressed 恰好一个为 true。
- 能力地图展示后端返回的六类能力；本周实验展示后端返回的目标/输入/工具/成功标准/时长。
- 第一课课程 section 展示后端返回的章节内容（章节标题、对照表、pre 模板块、量表等）。
- 页面不出现「服务不可用」提示。

异常场景：
- 响应缺失必填字段或 JSON 结构不合法时，页面按字段缺失展示兜底内容并出现「服务不可用」提示，不得白屏。

#### AC-FE-002 加载失败时降级内联数据

Given：
- 后端服务不可访问（连接失败、超时或返回 5xx）。

When：
- 用户打开站点或刷新页面。

Then：
- 页面展示与后端返回一致的兜底内容（三条路线、六类能力、本周实验、第一课全部章节）。
- 页面出现可见的「服务不可用」提示。
- 路线切换、能力地图、本周实验、第一课锚点跳转均照常工作。

异常场景：
- 后端在页面加载完成后的会话中途宕机时，已展示内容保持不变，后续仅进度保存类操作提示失败，页面不刷新、不白屏。

### FE-US-002 简易账号登录

- 页面/组件：进度面板中的注册/登录表单
- 展示内容：用户名输入、密码输入、提交按钮；注册与登录两态切换；当前登录用户标识
- 交互动作：提交后调用注册或登录端点；成功后保存会话令牌与用户名并刷新进度面板
- UI 状态：idle、submitting、success、error、logout
- 表单校验：用户名/密码非空；服务端错误（用户名已存在、密码错误）以可读文案展示
- 权限可见性：面板对所有人可见；未登录显示注册/登录表单
- 边界处理：请求失败显示提示且不丢失输入；已登录用户可退出登录

#### AC-FE-003 注册并登录成功

Given：
- 用户输入的用户名未被占用，密码非空。

When：
- 用户提交注册表单。

Then：
- 页面进入登录态，展示当前用户名与退出登录入口。
- 进度面板出现可编辑的进度控件（第一课完成状态、评估分、本周实验完成）。
- 刷新页面后登录态保持（令牌持久化）。

异常场景：
- 用户名已存在时展示「用户名已存在」类可读错误，表单保持登录前状态，令牌不被写入。
- 网络失败时展示失败提示，登录态不变。

#### AC-FE-004 已注册用户登录成功与退出

Given：
- 已存在使用该用户名与密码注册的账号。

When：
- 用户提交登录表单。

Then：
- 页面进入登录态并恢复该用户的服务端进度到进度面板。
- 展示当前用户名与退出登录入口。

异常场景：
- 密码错误时展示可读错误提示，不进入登录态。
- 点击退出登录后面板回到未登录表单态，进度控件恢复禁用/隐藏，令牌被清除。

### FE-US-003 学习进度保存与恢复

- 页面/组件：进度面板
- 展示内容：第一课完成状态（复选）、第一课评估分（0–10）、本周实验完成（复选）、保存按钮、保存时间
- 交互动作：修改后点保存写入服务端；加载时读取服务端进度回填
- UI 状态：idle、saved、saving、save-failed、logged-out
- 表单校验：评估分必须在 0–10 范围内或为空
- 权限可见性：仅登录用户可编辑
- 边界处理：保存失败保留输入并提示；未登录时提示先登录

#### AC-FE-005 保存并在再次登录后恢复

Given：
- 用户已登录，服务端进度存在或为空。

When：
- 用户设置第一课完成、评估分 8、本周实验完成并保存。

Then：
- 页面出现保存成功确认（如保存时间）。
- 用户退出登录后重新登录，进度面板回填第一课完成、评估分 8、本周实验完成。

异常场景：
- 保存时服务不可用，页面显示保存失败提示且控件保留当前输入值，不得回滚为旧值。

#### AC-FE-006 未登录用户不能编辑进度

Given：
- 用户未登录。

When：
- 用户查看进度面板。

Then：
- 面板显示注册/登录表单或「登录后使用进度」提示，进度控件不可编辑。
- 用户不得通过面板界面写入任何服务端进度。

异常场景：
- 未登录状态下主动请求进度接口时，页面展示未登录提示，不展示其他用户进度。

## 9. 后端输出规范

### BE-US-001 提供课程内容 API

- 输入语义：只读 GET 请求，无请求体
- 输出语义：HTTP 200，`{ "data": <内容> }`；内容结构见 API 文档
- 数据读写：只读内容存储，不写不删
- 权限规则：开放访问，无需认证
- 业务规则：返回内容与站点现状一致；第一课仅「入门」路线存在，builder/advanced 返回 404
- 安全要求：错误不泄露实现细节；JSON 响应
- 幂等与并发：GET 幂等；并发读返回一致结果
- 错误与边界：未知资源路径返回 404，code 明确

#### AC-BE-001 返回完整课程内容

Given：
- 后端已启动并完成内容初始化。

When：
- 客户端调用 `GET /api/v1/routes`、`GET /api/v1/capabilities`、`GET /api/v1/lab`、`GET /api/v1/lessons/beginner`。

Then：
- 各端点返回 HTTP 200 与 `{ "data": ... }`，内容含站点现状全部数据（三条路线、六类能力、本周实验字段、第一课全部章节）。
- 响应为合法 JSON，字段类型与 API 文档一致。

异常场景：
- `GET /api/v1/lessons/builder` 与 `advanced` 返回 404 与统一错误结构，不返回部分内容。

#### AC-BE-002 内容端点错误处理稳定

Given：
- 客户端请求不存在的资源路径。

When：
- 调用未定义端点。

Then：
- 返回 HTTP 404 与统一错误结构 `{ "code": ..., "message": ... }`。
- 响应不包含堆栈或内部路径。

异常场景：
- 请求方法不允许时返回 405 或 404 的统一错误，不返回 HTML 错误页。

### BE-US-002 提供账号注册登录与会话

- 输入语义：JSON 请求体 `{ "username": string, "password": string }`
- 输出语义：注册成功 HTTP 201、登录成功 HTTP 200，均返回 `{ "data": { "token": string, "username": string } }`
- 数据读写：写用户表；读用户以校验凭证
- 权限规则：注册/登录开放；受保护端点需 `Authorization: Bearer <token>`
- 业务规则：用户名唯一；密码单向散列存储，不存明文；令牌为随机不可猜测值
- 安全要求：错误不泄露是否已存在外的内部信息；不返回散列
- 幂等与并发：重复注册同一用户名失败（409 冲突）；并发注册同名只成功一次
- 错误与边界：用户名已存在 409；密码错误或用户不存在 401；字段缺失/非法 400

#### AC-BE-003 注册新用户并发放令牌

Given：
- 用户名未被占用，用户名与密码均为非空字符串。

When：
- 客户端调用注册端点。

Then：
- 返回 HTTP 201，响应含随机令牌与用户名。
- 使用该令牌访问受保护端点（如进度）返回该用户数据。
- 数据库中密码字段不是明文（无法直接还原为提交的密码）。

异常场景：
- 用户名已存在时返回 409 与统一错误，不覆盖既有账号、不返回旧令牌。

#### AC-BE-004 登录与令牌校验

Given：
- 已存在注册账号。

When：
- 客户端使用正确用户名与密码调用登录端点。

Then：
- 返回 HTTP 200，响应含新令牌与用户名。
- 使用该令牌可访问受保护端点。

异常场景：
- 密码错误或用户不存在时返回 401 与统一错误，不创建令牌。
- 使用无效或伪造令牌访问受保护端点时返回 401，不泄露用户数据。

### BE-US-003 提供按用户隔离的学习进度持久化

- 输入语义：读取为 GET（无请求体）；写入为 PUT，JSON 请求体为进度对象
- 输出语义：HTTP 200，`{ "data": { "progress": { "firstLessonCompleted": boolean, "evaluationScore": number|null, "weeklyLabCompleted": boolean, "updatedAt": string } } }`
- 数据读写：按令牌对应用户读写其进度行；无进度时首次写入创建
- 权限规则：仅持有有效令牌者访问自己的进度
- 业务规则：进度按用户隔离；写入覆盖该用户整份进度
- 安全要求：响应不泄露其他用户进度；错误不含堆栈
- 幂等与并发：同进度重复 PUT 结果一致；并发 PUT 以最后一次为准
- 错误与边界：未认证 401；字段类型/范围非法 400；evaluationScore 允许 0–10 整数或 null

#### AC-BE-005 读取与创建进度

Given：
- 用户未保存过进度。

When：
- 持有该用户有效令牌调用读取进度端点。

Then：
- 返回 HTTP 200，进度字段为默认值（未完成、无评估分、未完成）。
- 写入合法进度后再次读取，返回与已写入一致的值。
- `updatedAt` 为 ISO 8601 时间字符串。

异常场景：
- 无令牌或令牌无效时返回 401，不返回任何进度数据。

#### AC-BE-006 校验与隔离进度写入

Given：
- 用户 A 持有自己的有效令牌，已保存进度。

When：
- 使用用户 A 令牌写入新进度，再用用户 B 令牌读取。

Then：
- 用户 A 读取到最新写入值。
- 用户 B 读取到用户 B 自己的默认值，不包含用户 A 的任何进度字段。

异常场景：
- 请求体字段类型非法（如 firstLessonCompleted 为字符串）或 evaluationScore 超出 0–10 时返回 400 与统一错误，不写入任何数据。
